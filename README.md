# 🐃 Bubatag - Mobile App

## 📖 Sobre o Projeto

O **Bubatag** é o aplicativo móvel da plataforma IoT desenvolvida para o monitoramento inteligente e geolocalização de bubalinos, com foco nas necessidades da agropecuária da região do Vale do Ribeira.

O sistema integra os dados de coleiras eletrônicas equipadas com sensores GPS e fisiológicos, permitindo que os produtores acompanhem em tempo real a localização, os níveis de estresse e a saúde do rebanho em pasto aberto.

O objetivo é aliar o avanço tecnológico à gestão agropecuária para garantir eficiência produtiva e bem-estar animal.

---

## 🚀 Tecnologias Utilizadas

A aplicação foi construída visando performance e uma interface de usuário fluida, limpa e moderna:

- **React Native**  
  Framework para o desenvolvimento mobile multiplataforma.

- **TypeScript**  
  Tipagem estática para maior segurança e escalabilidade do código.

- **Tailwind CSS / NativeWind**  
  Estilização utilitária para um design consistente e responsivo.

---

## ✨ Funcionalidades

A estrutura do aplicativo conta com os seguintes módulos principais:

- **Autenticação**  
  Fluxo seguro de entrada e criação de contas de produtores.

- **Dashboard de Monitoramento**  
  Painel central que exibe estatísticas vitais do rebanho, como temperatura média, total de animais e coleiras ativas.

- **Gestão do Rebanho**  
  Interface dedicada para o cadastro de novos animais no sistema.

- **Alertas de Status**  
  Identificadores visuais em tempo real sobre a condição de cada animal, como:
  - Saudável
  - Estressado
  - Sem sinal
  - Fugiu

## 🛠️ Como Executar a Aplicação

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/mobile-plataforma_iot_monitoramento_bubalinos.git
```

### 2. Acesse o diretório da aplicação

```bash
cd mobile-plataforma_iot_monitoramento_bubalinos/mobile-bubatag
```

### 3. Instale as dependências

```bash
npm install
```

Ou, se preferir usar o Yarn:

```bash
yarn install
```

### 4. Inicie o servidor de desenvolvimento

```bash
npx expo start
```

### 5. Acesse o App

#### Dispositivo físico

Baixe o aplicativo **Expo Go** no iOS ou Android e escaneie o QR Code exibido no terminal.

#### Emulador

No terminal, pressione:

- `a` para abrir no emulador Android.
- `i` para abrir no simulador iOS.
